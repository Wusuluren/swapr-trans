隐私承诺

本地端侧优先，数据永不上云

SwaprTrans 坚守纯粹的开源与隐私理念。我们不收集任何个人数据，代码完全透明可审计。

  • 本地端侧神经运算 默认使用 Apple Native 神经引擎，翻译运算全程在本地芯片完成，不产生任何外发请求。
  • 绝不收集与上传输入文本 没有后台分析服务，没有遥测代码，不收集任何用户输入内容与应用使用习惯。
  • 密码框与隐私跳过 检测到安全输入框或密码字段时自动规避，杜绝敏感凭据泄露风险。
  • 100% 开源透明 所有源代码在 GitHub 开源，构建脚本全公开，任何人均可自由审查与本地编译。

开发者集成

通过 Swift Package Manager 接入

将 SwaprTransKit 作为依赖引入到你自己的 macOS App 中：

// Package.swift
dependencies: [
    .package(url: "https://github.com/linrol/swapr-trans.git", from: "1.0.0")
],
targets: [
    .target(
        name: "YourAwesomeApp",
        dependencies: [
            .product(name: "SwaprTransKit", package: "swapr-trans")
        ]
    )
]
import SwaprTransKit

// 启动原位掉包快捷监控服务
SwaprTransConfig.shared.isEnabled = true

// 在你的 SwiftUI 视图或设置面板中直接嵌入
SwaprTransSettingsView()

安装使用

快速安装与配置

  • 01 下载最新版本的 SwaprTrans-1.0.0.dmg 安装包；
  • 02 双击打开 DMG 文件，将 SwaprTrans.app 拖拽至 Applications 应用程序文件夹；
  • 03 首次打开：由于当前采用个人 Ad-hoc 签名，若遇系统拦截提示，请在 Finder 中右键点击 SwaprTrans.app → 点击「打开」；
  • 04 授权：首次启动后，请按 macOS 引导授予「辅助功能」(Accessibility) 权限，以支持实时光标定位与选区原地掉包。
立即下载 SwaprTrans-1.0.0.dmg (1.9MB)

克隆仓库后，在终端执行一键安装脚本即可就地编译并安装到 /Applications：

git clone https://github.com/linrol/swapr-trans.git
cd swapr-trans
./scripts/install.sh
